# UF-013 — Build and pin the offline taxonomy package cache

[Back to execution backlog](../execution_tickets.md)

**Priority / size:** P0 / L

**Depends on:** UF-012, UF-020

**Outcome:** Historical parsing resolves standard taxonomy resources offline.

**Acceptance criteria:**

- The cache is built from a published-vintage superset rather than from the
  accession inventory: every SEC-published version of `us-gaap`, `dei`, `srt`,
  `country`, `currency`, `exch`, `stpr`, document/entity, role, and reference
  schemas from the Release 1 filing start forward. The superset is bounded,
  enumerable from SEC's taxonomy listings, and knowable before UF-021 exists.
- The set of cached vintages is recorded as an explicit, versioned list, so a
  later coverage check can name exactly what was fetched.
- Once UF-021 produces the accession inventory, a coverage check confirms that
  every taxonomy version the inventory references is present. The check
  verifies the superset; it does not define it, and UF-013 does not depend on
  it. A gap found by the check is a defect in the superset list, not a
  redefinition of the cache.
- Resources are installed as XBRL Taxonomy Packages with an offline URI
  catalog; filing extensions remain in accession storage.
- Every package is fetched through the UF-020 transport client, so taxonomy
  acquisition shares the declared user agent, aggregate rate cap, conditional
  requests, and request logging. No component may open its own connection to
  an SEC host.
- Package name, version, SHA-256, and URI catalog SHA-256 are included in build
  manifests.
- Normal parsing fails closed on an attempted network taxonomy resolution and
  emits the unresolved URI.
- An offline test loads representative taxonomy vintages from the earliest,
  middle, and latest supported years.
